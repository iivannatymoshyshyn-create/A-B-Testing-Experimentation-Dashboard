# 📊 A/B Testing & Experimentation Dashboard (Tableau)

🔗 **[View Interactive Dashboard on Tableau Public](https://public.tableau.com/app/profile/ivanna.tymoshyshyn/viz/ABtest_17737756240930/ABTest)**

## 📌 Overview
An interactive Tableau dashboard for evaluating A/B test performance across user segments, channels, and conversion funnel metrics.
## 🔑 Key Features & Dimensions Analyzed
* **Traffic & Session Dynamics:** Daily session volume comparisons between test groups.
* **Demographics & Devices:** Segmentation by continent, country, and device type (Desktop, Mobile, Tablet).
* **Acquisition Channels:** Channel performance analysis (Direct, Organic, Paid, Social Search).
* **Conversion Funnel Metrics:** Detailed event breakdown from `first_visit` and `add_to_cart` to `begin_checkout` and `add_payment_info`.
